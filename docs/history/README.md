# Research log (Spanish)

Day-by-day record of the competition, kept as it was written. Each Frontier has a results report
(`FRONTIER<N>_RESULTS.es.md`) with the diagnosis, the candidates measured, the registered gate and the Kaggle
verification, and a continuation note (`RESUME_FRONTIER<N>.es.md`) with the state at the end of that session.

Links to code and receipts are relative to this folder (`../../scripts`, `../../results`, `../../notebooks`).
Commands quoted in these files were run from the repository root when the scripts still lived there; today the same
scripts live in `scripts/` (`python scripts/<name>.py`) and the tests in `tests/`.

| Topic | Files |
|---|---|
| Competition rules, tools, lessons learned | `GUIA_PARA_EL_PROXIMO_CHAT.es.md` |
| Initial research and papers | `RESEARCH.es.md`, `RESEARCH_2026_09_12.es.md` |
| First agent, live diagnosis, learned critic | `RESULTS.es.md`, `LIVE_DIAGNOSIS.es.md`, `ML_RESULTS.es.md` |
| Top-27 / top-100 opponent analysis | `GOLD_RESEARCH.es.md`, `ANALISIS_2700.es.md`, `TOP100_ESTRATEGIAS.es.md`, `TOP100_CUATRO_PARTIDAS.es.md` |
| Frontier 1–21 results and continuation notes | `FRONTIER*_RESULTS.es.md`, `FRONTIER*_RESEARCH.es.md`, `RESUME_FRONTIER*.es.md` |
| Review of the public V41 baseline | `V41_REVIEW.es.md`, `RESUME_REVIEW_V41.es.md` |
